Saya adalah mahasiswa **Teknik Informatika** di **Universitas Teknologi Bandung (UTB)**, Fakultas Industri Kreatif, yang sedang aktif membangun berbagai project — mulai dari sistem informasi rumah sakit berbasis Android, aplikasi desktop dengan Java Swing, hingga eksplorasi UI/UX di Figma. Di luar coding, saya juga senang mengulik **worldbuilding** dan menulis cerita — karena buat saya, membangun aplikasi dan membangun cerita sama-sama soal merancang sistem yang koheren. ✍️
